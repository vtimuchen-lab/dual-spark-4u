# dual-spark-4u — 5U-модуль с 2 × MSI EdgeXpert AI (DGX Spark-class) и раздельным охлаждением для 18U шкафа

Параметрический OpenSCAD-проект самостоятельного 5U-узла: фронтальная панель
ЦМО ФП-5 с двумя вырезами под 140-мм вентиляторы, алюминиевая base_plate на
полке шкафа, два holder'а (адаптация
[alexliesenfeld/dgx-spark-printables](https://github.com/alexliesenfeld/dgx-spark-printables),
CC BY-NC 4.0), два независимых воздуховода 140 → передняя решётка MSI, свободный
выхлоп в горячую зону шкафа. Имя репозитория историческое: v1 проектировалась
под 4U-корпус (`docs/TZ_v1_chassis.md`), v2 — модуль в шкафу (`docs/TZ.md`).

```
[магнитный фильтр] → [решётка ARCTIC 140] → [ФП-5] → [Arctic P14 Pro PST 27]
    → [воздуховод 200 = пленум 50 (R36) + сопло 150] → [EPDM 5] → [MSI 150] → [выхлоп ≥ 90]
                                                   × 2 тракта, оси x = ±98 от центра панели
```

## Статус: замеры внесены — панель, разметка полки, holder и воздуховод готовы к изготовлению

Замеры раундов 1+2 (шкаф, ФП-5, MSI, вентилятор, решётка) внесены в
`scad/params.scad` (`docs/08_measurements.md`). Модуль собирается целиком.
Экспортированы окончательные STL holder'а, воздуховода (два варианта),
заслонок (уголки не печатаются — крепление через штатные
отверстия), DXF и таблицы отверстий для резки панели ФП-5 и сверловки
полки (плиты нет: holder'ы и электроника — прямо на перфорированной полке). Ждёт замера только рамка термоконтроллера (п.11); её STL появится
автоматически после внесения размеров. DC-гнездо — кабельная «мама», стойка не нужна.

**Важно:** полоса над вентилятором под рамку контроллера — 34.5 мм, корпус
контроллера по защёлкам должен быть не выше 27.7 мм (варианты —
`docs/03_measure_checklist.md`). Датчик контроллера — в притоке перед
решёткой, минимум PWM ≈ 40 % (`docs/07_rack_layout.md` §4).

## Для инженера

**Готово к изготовлению**
* ФП-5: 2 × Ø138 + 8 пазов M4 (124.5…126) — `docs/drawings/panel_fp5.dxf`,
  `panel_fp5_holes.csv`; для ручной разметки — шаблон 1:1
  `docs/drawings/fan_template_fp5_A4.pdf`. Отверстия рамок контроллеров — после
  замера контроллера.
* **Плиты нет:** holder'ы и электроника крепятся прямо к перфорированной полке
  шкафа (8 × Ø4.5 + 10 × Ø3.4 насквозь, гайки снизу; попало в перфорацию —
  использовать её) — разметка `docs/drawings/shelf_drill.png/.dxf`,
  `shelf_drill_holes.csv`. Единый блок = полка + модуль, если полка снимается со
  стоек. Плита Al 3 мм — опция (`use_base_plate = true`).
* Печать (тест — PETG): holder, воздуховод (+ герметичный вариант), заслонки,
  стойка вентилятора — `stl/`; комплект на один тракт — `stl/kit/`.
  Крепёж и покупное — `docs/05_bom_hardware.md`, режимы печати — `docs/09_print_materials.md`.

**Ждёт**
* Рамка контроллера `ctrl_bezel` — контроллер в пути (замеры п.11a–f).
* Уточнения: лист ФП-5 без временного фильтра (п.4a), толщина P14 Pro в углу по
  амортизаторам (п.13b — может сменить болт сэндвича M4×40 на M4×45), толщина
  магнитного фильтра (п.21) — `docs/03_measure_checklist.md`.

**Где нужен взгляд**
1. Аэродинамика (`docs/04_aero_estimate.md`) — оценки, не замеры: линейная
   характеристика вентилятора, Δp фильтра 100 mesh 3–6 Па, подпор перед сотами
   3–7 Па; цель 40–60 м³/ч на тракт ≈ 1200–1500 об/мин.
2. Подача под днище + заслонка против герметичного воздуховода; направление
   потока в нижней решётке MSI — испытание на настольном тракте
   (`docs/07_rack_layout.md` §4a).
3. Датчик контроллера на притоке → постоянный минимум PWM ≈ 40 % (≈ 42 дБ);
   альтернатива — датчик в T_out (`docs/07_rack_layout.md` §4).
4. Пакет болта сэндвича: запас 0.7 мм за гайкой (п.13b).
5. Пластик holder'а у выхлопа: PETG или ASA — по T_out под нагрузкой (09).

**Как пересобрать:** OpenSCAD 2021.01, `./scripts/export_all.sh` (OK / SKIP / FAIL по
каждой детали). Все размеры — только `scad/params.scad` с метками [MEAS] / [SRC] /
[ASSM] / TO_MEASURE; проверки геометрии — assert'ы `part_checks`, `rack_checks`,
`ctrl_checks` там же. Решения и журнал — `CLAUDE.md`, ТЗ с дополнениями — `docs/TZ.md` §10.

Что означают цвета на 3D-рендерах:

| Цвет | Что это |
|------|---------|
| светло-серый лист с отбортовкой | панель ЦМО ФП-5 (на виде спереди — тёмная) |
| чёрные кольца со спицами | решётки ARCTIC 140 снаружи панели |
| полупрозрачный голубой | воздуховод (пленум + сопло) |
| серый | holder (опоры, стенки, стойка T_out) |
| чёрный корпус с голубой и оранжевой полосой | макет MSI EdgeXpert: голубое — соты (вход), оранжевое — задний выхлоп |
| оранжевая планка | заслонка `bypass_block` в пазах holder'а (для испытаний) |
| розовый полупрозрачный объём | зона свободного выхлопа ≥ 90 мм за MSI — воздух, не деталь |
| зелёная площадка с надписью | место на полке: справа DC-гнездо 12 В и WAGO 221-413, слева резерв (ESP32) — не деталь, не печатается |
| полупрозрачная серая полоса под модулем | полка шкафа (плиты нет) |

На виде сбоку зелёный пунктир над панелью — полоса 34.5 мм под рамку
термоконтроллера (появится после замера контроллера).

## Как пользоваться

1. `./scripts/export_all.sh` — пересобирает всё; в выводе OK/SKIP по деталям.
2. Панель: вырезы и пазы по `docs/drawings/panel_fp5.dxf` или
   `panel_fp5_holes.csv`; вручную — шаблон 1:1 `fan_template_fp5_A4.pdf`
   (печать «Фактический размер», совместить края панели, кернить через бумагу). Полка: `shelf_drill.png` / `shelf_drill_holes.csv`.
3. Печать по `docs/05_bom_hardware.md` и `docs/09_print_materials.md` (тест — всё PETG; holder — ASA, если выхлоп > 50 °C), сборка по
   `docs/07_rack_layout.md` §5.
4. Когда придёт контроллер — вписать его размеры (`ctrl_*`, `ctrl_probe_d`,
   `docs/03_measure_checklist.md` п.11) в `scad/params.scad` и снова запустить экспорт.
