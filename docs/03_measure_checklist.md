## Если полоса над вентилятором мала для контроллера

Полоса = 221.5 − `shelf_top_z` − 150 = 31.5 мм при `shelf_top_z` = 40.

| Вариант | Полоса / условие | Что меняется |
|---------|------------------|--------------|
| Корпус по защёлкам ≤ 24.7 мм по высоте | 31.5 | ничего |
| Опустить полку на одно отверстие стойки (12.7 или 15.875) | 44.2 или 47.4 → корпус ≤ 37.4 / 40.6 | `shelf_top_z` = 27.3 или 24.1; проверить место над ИБП |
| Рамка сбоку от вентилятора (полоса x 175…222 от оси панели: дальше — стойка шкафа, а винты лапок идут сзади) | ширина ≤ ~47 | новая разметка; рамка вне оси трака |
| Контроллер за панелью, дисплей в окне | — | запасной вариант из TZ §4.1 |

## Как вносить

```sh
# scad/params.scad: заменить undef на измеренное, например
#   ctrl_cut_w = 45;  ctrl_cut_h = 22;  ctrl_w = 47;  ctrl_h = 24;  ctrl_d = 22;
#   ctrl_frame_w = 48;  ctrl_frame_h = 29;  ctrl_frame_t = 3;  ctrl_clip_t = 2;
#   ctrl_probe_d = 4;                         (числа — только пример формата)
./scripts/export_all.sh     # в выводе: OK/SKIP по каждой детали
```
