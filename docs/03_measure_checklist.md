# Чек-лист замеров

Раунды 1 и 2 внесены (сводка и привязка к параметрам — `docs/08_measurements.md`).
Ниже — что осталось. Значения вносятся в `scad/params.scad` вместо `undef`,
затем `./scripts/export_all.sh`. Деталь экспортируется, как только заполнены
все TO_MEASURE, от которых она зависит.

## Если полоса над вентилятором мала для контроллера

Полоса = 221.5 − `shelf_top_z` − 150 = 31.5 мм при `shelf_top_z` = 40.

| Вариант | Полоса / условие | Что меняется |
|---------|------------------|--------------|
| Плата ≤ 24.7 мм по высоте | 31.5 | ничего |
| Опустить полку на одно отверстие стойки (12.7 или 15.875) | 44.2 или 47.4 → плата ≤ 37.4 / 40.6 | `shelf_top_z` = 27.3 или 24.1; проверить место над ИБП |
| Рамка сбоку от вентилятора (полоса x 175…241 на панели, выше уголков) | ширина ≤ 64 | новая разметка; рамка вне оси трака |
| Контроллер за панелью, дисплей в окне | — | запасной вариант из TZ §4.1 |

## Как вносить

```sh
# scad/params.scad: заменить undef на измеренное, например
#   ctrl_w = 50;  ctrl_h = 24;  ctrl_d = 18;  dc_jack_d = 11.5;
./scripts/export_all.sh     # в выводе: OK/SKIP по каждой детали
```
