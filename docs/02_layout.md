Чертежи генерируются из `scad/params.scad` скриптом `scripts/make_drawings.py`:

| Чертёж | Файл | Статус |
|--------|------|--------|
| Разметка панели ФП-5 (вырезы, пазы M4) | `drawings/panel_fp5.svg/.png` | горизонталь окончательна; вертикаль — по формуле, пока `shelf_top_z` TO_MEASURE |
| Сверловка base_plate | `drawings/base_plate.svg/.png` | отверстия относительно оси и переднего края окончательны; габарит TO_MEASURE |

| 3D-превью | `renders/*_PREVIEW.png` | на подстановочных значениях (см. §7) |

## 1. Система координат модуля

* X — ширина, 0 на оси панели/плиты, вправо +;
* Y — глубина, 0 — задняя плоскость панели ФП-5 (лист в y < 0), назад +;
* Z — высота, 0 — верх полки (= низ base_plate).

## 2. Продольная цепочка трака (y, мм)

| y | Элемент |
|---|---------|
| −(panel_t + 3) … −panel_t | решётка ARCTIC 140 (снаружи) |
| −panel_t … 0 | лист ФП-5 (`panel_t` TO_MEASURE); отбортовка 10 мм уходит в +Y по периметру |
| 0 … 27 | Arctic P14 Pro PST 140×140×27 |
| 27 … 33 | входной фланец воздуховода 150×150×6, 4 гнезда гаек M4 |
| 33 … 77 | пленум 135×135 |
| 77 … 141 | сопло 135×135 → 145×57 |
| 141 … 147 | выходной фланец 181×78×6, 4×M3 в стойки holder'а |
| 147 … 152 | EPDM 5 |
| 152 … 303 | MSI EdgeXpert 151 |
| 303 … 307 | задний стопор |
| 303 … 393 | свободный выхлоп 90 |

Holder: y = 147…307, ширина 181, стойки 109 над плитой. base_plate: y = 2…(≥ 332),
глубина по полке. Полная длина модуля от задней плоскости панели — **393 мм**,
плюс кабели сзади ~80 → в шкафу 600 мм помещается с запасом.

## 3. Поперечная раскладка (x от оси)

| x | Что |
|---|-----|
| ±98 | оси траков (вентиляторы, воздуховоды, MSI); шаг 196 |
| ±7.5 … ±188.5 | holder'ы (181 каждый, зазор между ними 15) |
| ±23 … ±173 | воздуховоды (150) и входные фланцы |
| ±178 … ±208 | уголки panel↔base_plate (30 шт. ширина, центр ±193) |
| ±175 … ±(плита/2 − 2) | полосы электроники (≈45 мм при проёме 450.85) |
| ±(rack_opening_w/2 − 3) | края base_plate |
| ±241.3 | края панели ФП-5 |

Вырезы Ø138 на панели: центры на 143.3 и 339.3 мм от левого края панели, 196 между ними.

## 4. Вертикаль (z над полкой)

| z | Что |
|---|-----|
| 0…3 | base_plate |
| 3…8 | дно holder'а |
| 8…148 | вентилятор (ось **78** = плита 3 + 75) |
| 52 | дно MSI (ось MSI = 78) |
| 104 | верх MSI |
| 112 | верх стоек holder'а |
| 148 | верх вентилятора/фланца; панель 221.5 высотой |

На панели (z от нижнего края ФП-5): ось выреза = `shelf_top_z + 78`, допустимо
**90…131.5** (фланец 150 ≥ 15 мм от краёв) ⇒ `shelf_top_z ∈ [12; 53.5]`.
Если полка не попадает в этот диапазон — переставить её на один U-шаг (44.45)
либо изменить `fan_axis_above_plate` (тогда пересчитать высоту holder'а —
автоматически).

## 5. Панель ФП-5 — что делается

Два выреза Ø138 (лобзик/коронка/лазер) и 8 пазов 4.5×5.5 мм (сверло 4.5 +
надфиль по диагонали — под межцентровое 124.5/125). Отверстия уголков: 2×Ø4.5
на x = ±193 от оси, z = `shelf_top_z` + 20 и + 51. Крепёжные уши — без
изменений. Резать только после замера `shelf_top_z` (чертёж `panel_fp5`
перестроится с реальной вертикалью).

## 6. Электроника на base_plate

Две полосы по бокам (x = ±175…±~220, y = 59…141), сетка M3 шаг 10:
слева — PWM-контроллер трака 1 + WAGO «+»/«−»; справа — контроллер трака 2 +
стойка DC-гнезда (гнездо смотрит назад). Кабели датчиков T_out идут вдоль
наружных стенок holder'ов (вне воздуховода и выхлопа).

## 7. Подстановочные значения для PREVIEW-рендеров

Сборка не собирается при `undef`. Для картинок `scripts/export_all.sh` передаёт
**не измерения, а подстановки**: `rack_opening_w = 450.85` (EIA-310 номинал),
`shelf_top_z = 25`, `shelf_depth = 400`, `panel_t = 1.2`,
`panel_hole_pitch_v = 31.75`. Ни одно из них не является размером вашего шкафа.

## 8. Проверки в модели

`rack_checks()` (assert): пять TO_MEASURE заданы; плита шире пары траков;
уголки внутри плиты и keep-out панели; полосы электроники ≥ 30 мм; ось выреза в
допуске; полка ≥ 330 и несёт модуль; модуль короче шкафа. `part_checks()`:
детали помещаются на стол 250×250, площадь выхода < входа.
